# LinkStudy 隐私政策

> 当前版本：2026-08-15
> LinkStudy 是基于 Sked（https://github.com/Mashiro0619/Sked，AGPL-3.0）的二次开发项目，由 TheoHowie 维护（https://github.com/theohowie/linkstudy）。

## 概述

本隐私政策用于说明 LinkStudy 网课链接采集与课程表管理应用在提供网课链接采集、课程管理、自动排课、数据导入导出、外部链接跳转及相关辅助功能过程中，对信息的处理方式、处理边界、适用范围以及用户可知悉的基本规则。

## 数据模式

- **本地优先**：课程、链接、设置和备份默认保存在当前设备本地。
- **外部访问**：仅在你主动触发导入、导出、分享、打开外部链接或检查更新时，才会涉及外部交互。
- **账号与遥测**：默认不收集。不要求注册 LinkStudy 账号，不默认启用分析、广告或云端画像。

## 适用范围

本隐私政策适用于 LinkStudy 网课链接采集与课程表管理应用及其直接相关的本地功能、悬浮窗采集功能、课程导入导出功能。本政策旨在说明在你使用本应用过程中，应用会在何种情况下处理你的信息、处理何种类型的信息、将信息保存于何处，以及在何种情况下可能与外部系统发生交互。

需要说明的是，本应用为本地优先的软件产品，不以建立用户账号体系、持续上传用户数据或实施行为画像为基础运行模式。因此，本政策所述的信息处理方式主要围绕本地存储、文件导入导出、悬浮窗采集、系统分享以及外部链接跳转等场景展开。

## 本地存储

课程与链接数据、排课结果、相关设置和完整应用备份内容会保存在你的设备本地或浏览器本地存储中。应用不会自动把这些本地数据上传到开发者控制的服务器，也不会在后台持续传输你的课程内容、链接或设置内容。

## 悬浮窗与采集

当你在其他应用中复制网课链接或使用系统拖放功能时，可通过悬浮窗把链接采集进本应用。剪贴板内容的读取仅发生在本应用处于前台、或你主动点击悬浮窗"粘贴"并跳转前台确认时；拖放内容由系统拖放事件携带。上述采集行为均在你的设备本地完成，采集到的链接与课程信息保存在本地。应用不会在后台监听或读取你的剪贴板内容。

## 导入导出与备份

当且仅当你主动选择导入文件、粘贴 JSON 文本、主动保存文件或主动执行导出操作时，应用才会访问你指定的本地文件内容、读取你粘贴的文本或向你指定的位置写出文件。该类数据可能包括课程 JSON 文件、完整应用备份 JSON 文件等。完整应用备份会导出课程、链接、应用设置等本地数据。恢复完整应用备份会替换当前应用数据，应用会在恢复前要求你确认。除非你进一步主动选择，否则单纯的导入导出行为不会将你的文件内容自动发送至外部服务。

## 分享与打开链接

- **分享**：当你主动使用分享功能时，应用会将你明确选定的导出文件交由系统分享面板或你选择的目标应用处理。该操作属于你主动发起的设备级分享行为。应用无法控制第三方应用在接收文件后的处理方式。
- **打开网课链接**：当你点击课程中的网课链接或 GitHub 仓库、外部链接时，应用会调用系统浏览器或其他外部应用完成访问请求。此类访问行为一旦离开本应用控制范围，相关数据处理即受对应第三方网站、平台或应用自身的规则和政策约束。请你在访问外部链接前自行审阅第三方平台的相关政策。

## 默认不收集的内容

在默认状态下，本应用不要求你注册 LinkStudy 账号，不默认启用分析统计、个性化广告、广告标识符跟踪、云端画像或云端自动备份功能。本应用不包含崩溃报告、错误日志自动上报或使用情况遥测功能。

应用启动时会静默请求隐私政策页面以检测版本更新（在部署自有页面后生效），该请求不会携带你的课程数据或个人标识信息。

## 可选 AI 功能（预留）

如后续版本提供 AI 辅助功能（如课程信息整理、排课建议），该功能需你主动填写 OpenAI 兼容接口的 Base URL、API 密钥与模型名，请求将直连你配置的接口端点。API 密钥会在可用时通过平台安全存储层加密保存，不写入普通数据文件。未配置密钥时，AI 功能入口置灰或隐藏，其余功能不受影响。请求失败或超时不会阻塞应用主流程。请你在使用前确认所配置接口的隐私政策、配额限制与日志保留规则。

## 用户注意事项

- 你应确保采集、导入、导出、分享或处理的内容系你有权处理的信息；
- 你应妥善保管导出的文件，避免在不受信任的环境中传播；
- 如你通过外部网站、浏览器或第三方应用完成后续操作，应自行承担对第三方规则进行审查与选择的责任；
- 本应用提供的是网课链接采集与课程表管理工具，不对第三方平台的稳定性、持续可用性、内容准确性或数据处理方式作出额外保证。

## 政策更新

本隐私政策可能随功能演进进行调整。重大变更会在应用内隐私政策确认环节或本页面显著位置提示，当前版本号见页面顶部。你继续使用本应用即视为认可更新后的政策。
